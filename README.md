# Customer Trends: End-to-End Data Analytics Workflow
### Python | SQL | Power BI

This project demonstrates an end-to-end customer shopping behavior data analytics workflow using Python(panda), PostgreSQL, and Power BI. The dataset was cleaned, analyzed, and visualized to generate insights and support decision-making.

## 🚀 Project Overview
* **Data Engineering (Python):** Cleaned and transformed raw datasets using Pandas.
* **Database Management (SQL):** Migrated data to a relational database for querying.
* **Business Intelligence (Power BI):** Developed an interactive dashboard to visualize KPIs.

## 🛠️ How to Use This Project

### 1. Setup & Data Cleaning
Clone the repository and run the Python notebook:
`git clone https://github.com/Mariak11/customer-behavior-analysis.git`

* Open `SalesAnalysis.ipynb`.
* Run the cells to explore and clean the data.

### 2. SQL Analysis
* Execute `customer_behavior_sql_queries.sql` in your SQL environment. I used Postgresql.

### 3. Visualization
* Open `customer_behavior_dashboard.pbix` to view the interactive dashboard in Power BI.

**How to Run**
Clone the repository
Install required Python libraries such as panda
Run the Jupyter Notebook
Execute SQL queries in PostgreSQL
Open the Power BI dashboard file
